# 🚀 Funngro Smart 2-Page Web Application

A modern, ultra-responsive, SEO-optimized 2-page website built for **Funngro** to connect Companies with Teen Freelancers.

## ✨ Features
- **Dual-Mode Toggle:** Seamless switching between **For Companies (Hire)** and **For Teens (Earn)** views.
- **Glassmorphism UI:** Modern dark mode design with responsive card grids and subtle micro-interactions.
- **100% Mobile & Desktop Responsive:** Fully tested across mobile viewports, tablets, and large screens.
- **SEO & Schema.org Ready:** Configured with OpenGraph meta tags, twitter cards, and JSON-LD structured data.

## 🛠️ Tech Stack
- HTML5 / CSS3 / JavaScript (Vanilla)
- Google Fonts (Inter) & FontAwesome Icons
- Hosted on **Vercel**
